# WatchNeuron

基于 Vue 3 的手写数字识别与神经网络逐层可视化实验台。

## 功能

- 在画布中手写数字，自动标准化为 `28 x 28` 灰度输入。
- 使用由 9,000 个 MNIST 样本训练的默认模型进行本地推理。
- 显示每一层的连接、激活强度、活跃占比和 0-9 概率。
- 自由添加或删除隐藏层，调整神经元数量与激活函数。
- 架构修改后可直接在浏览器中重新训练，并实时查看轮次、损失与验证准确率。
- 训练可随时暂停并从当前样本继续，保留权重、进度和最新信号采样。
- 完整训练自动写入本地模型库，暂停时也可主动保存当前权重快照。
- 模型库支持载入、重命名、筛选和删除，模型数据保存在浏览器 IndexedDB 中。
- 载入模型后可设置任意正整数追加轮数，在现有权重基础上继续微调；微调结果会作为新记录保留。
- 学习率只要求是大于 0 的有限数值，不设置额外上限。
- 提供 SGD、Momentum、Adam、RMSProp 和 AdaGrad 五种完整优化器，并可在独立配置页查看、应用建议参数和调整对应配置。
- 推理和训练采样均支持逐层步进；训练时可分别检查前向激活与反向梯度的具体数值。
- 训练期间同步采样输入图像、识别结果、逐层激活与反向梯度，并显示双向传播状态。
- 通过独立样本库页面管理手写数据，可筛选、修改标签、切换训练/测试归属，并进行单条或批量删除。
- 样本库可随时启用或关闭内置 MNIST 数据源；默认启用，关闭后训练与验证只使用用户自己的样本。
- 使用 Zig 编写并直接编译的 Wasm 内核执行推理、前向训练、反向传播和优化器更新。
- 浏览器训练由 Web Worker 调度 Zig/Wasm 内核，计算不阻塞绘图与界面交互。
- 架构偏好保存在浏览器本地，不依赖后端服务。

## 环境

- Node.js `>=22.13.0`
- Zig（仅重新编译 Wasm 时需要）

## 开发

```powershell
npm install
npm run wasm:build
npm run dev
```

本地地址默认为 `http://localhost:5173/`。

## 校验

```powershell
npm test
```

该命令依次执行 TypeScript 类型检查、Wasm 模型烟雾测试和生产构建。

## 模型

`public/model.json` 包含默认的 `784 -> 32 -> 10` 校准模型、测试准确率和演示样本。需要在本地重新生成默认模型时运行：

```powershell
npm run model:train
```

训练脚本使用固定随机种子和 npm 的 MNIST 数据集，便于复现结果。

## 浏览器重新训练

架构编辑器支持 1-4 个隐藏层，每层至少 8 个神经元且不设数量上限，并可分别选择 16 种已实现的激活函数。修改架构后，在训练面板设置轮次与学习率并开始训练，训练完成的权重会立即接入同一套 Wasm 推理与可视化流程。学习率只校验为大于 0 的有限数值，不设置上限。

顶部“优化器”页面提供五种优化器的说明、公式与一键应用的建议参数。SGD 直接使用当前梯度；Momentum 可配置 `[0, 1)` 范围内的动量系数；Adam 可配置 `beta1`、`beta2` 与 `epsilon`；RMSProp 可配置平方梯度衰减率与 `epsilon`；AdaGrad 累计历史平方梯度并提供数值稳定项。所有优化器更新均由 Zig/Wasm 执行，当前设置保存在浏览器本地，并同时用于重新训练和追加微调。

实验台信号流标题右侧提供逐层步进开关。推理时可以从输入层逐步前进到 Softmax 输出层；训练采样出现后还可切换为反向传播，从输出层逐步回到输入层。步进面板会列出当前方向绝对值最高的神经元及其激活值、反向梯度，网络画布同步突出已经传播到的层与当前传播边界。

手写数字完成后，可以选择标签并将当前输入加入训练集或测试集。自定义样本保存在浏览器本地。顶部“样本库”页面可用于查看缩略图、筛选、批量选择、修正标签、调整数据集归属和删除样本，并提供 MNIST 数据源开关。开关默认启用，此时自定义样本会与内置的 4,000 个训练样本和 1,000 个测试样本合并；关闭后 Worker 不再加载 MNIST，只使用自定义样本。

模型库中的任意完整模型或暂停快照都可以重新载入。载入后，训练面板会同时提供“从头重新训练”和“追加微调”两个入口；设置的轮数表示本次追加轮数，微调会保留载入模型的当前权重并继续训练。完成后自动生成新的模型库记录，显示累计训练轮数；暂停后也可保存当前微调快照。取消或训练失败不会覆盖原先载入的模型。

浏览器训练使用 `public/mnist-training.bin` 中的稀疏二值 MNIST 数据。Worker 将模型权重、激活、梯度和优化器状态映射到 Wasm 线性内存，每个样本由 Zig 导出的 `train_sample` 完成前向传播、Softmax 损失、反向传播及参数更新；JavaScript 只负责数据调度、暂停和可视化采样。需要重新生成训练数据时运行：

```powershell
npm run data:build
```

所有识别、训练与数据加载都在本地浏览器中完成；项目不包含 Sites 配置，也不会自动发布或上传数据。
